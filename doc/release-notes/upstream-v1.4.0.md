# Resin v1.4.0 (upstream lineage)

> Provenance: release notes of upstream `Resinat/Resin` v1.4.0, kept verbatim.
> Both lineages spent the same version numbers on different releases, so the
> fork's own v1.4.0 lives in [`v1.4.0.md`](v1.4.0.md) and this file preserves
> the upstream text without attributing it to the fork release.

## Changes

- Added proxy chaining with subscription-level relay and exit roles.
- Request logs show relay details when available.
- WebUI remembers page sizes and improves subscription status labels.
- Expired administrator sessions now return to login.

## Upgrade Notes

- Proxy chaining is off by default.
