# Resin v1.8.0

This fork release merges Resinat/Resin through upstream v1.4.1 into the fork's v1.7.1 line.

## Changes

- Added optional subscription-level proxy chaining, relay selection, and relay details in request logs. Chaining is off by default. Relay membership now stays current even when no platforms are registered.
- Added composable platform tag filters and lease account search. The WebUI remembers page sizes, improves subscription and request log views, and returns expired administrator sessions to sign-in.
- Improved subscription parsing for QUIC, VMess HTTP headers, HTTPS proxy names, and AnyTLS providers. Builds use Go 1.26.10 and retain sing-box v1.12.21 from the fork.
- Retained fork features including probe scripts, routing latency controls, and passive health classification.

## Upgrade and rollback

Back up your deployment configuration and all Resin data directories with Resin stopped. Startup may migrate legacy platform regex filters into composable rules. Earlier releases cannot represent all of these rules. To roll back, stop the new version and restore the old image and the matching pre-upgrade data backup.

REALITY compatibility depends on the server version and configuration. This release keeps the fork's existing REALITY implementation and does not include the experimental dependency patch. The standard release still omits the optional gVisor userspace stack required by WireGuard outbounds.
